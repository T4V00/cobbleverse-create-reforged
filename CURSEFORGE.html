Before you start

Tested and working with COBBLEVERSE 1.8.0 (Cobblemon 1.8.4, Fabric Loader 0.19.5), Create Reforged 6.0.10.3 and Create Aeronautics 1.3.2-4.

Made with AI. This mod was built with heavy help from an AI assistant (Claude), so it is "vibe-coded". It was tested in a real COBBLEVERSE world, both single player and LAN, but it is a beta. Back up your worlds before using it.

Installation

  1. Install the modpack. Get COBBLEVERSE (Fabric, Minecraft 1.21.1).
  2. Add the mods. Put these in the mods folder:
    • Create Reforged [Unofficial]
    • Create Aeronautics [Unofficial] and its dependency Sable
    • This mod
  3. Disable ScalableLux. COBBLEVERSE ships ScalableLux-0.1.0.1+fabric.d0d58ab-all.jar, and Sable (required by Create Aeronautics) refuses to load with it. In the CurseForge app, open the modpack's mod list and turn ScalableLux off, or rename the file in mods so it ends in .disabled. If you skip this, the game stops at launch with "Mod 'Sable' is incompatible with any version of mod 'ScalableLux'".
  4. Add the textures. Put the official Create jar and the official Create Aeronautics jar in the resourcepacks folder. The two ports read their textures from those jars; see their pages for details.
  5. Launch the game.

What it fixes

1. The game freezes on the loading screen

Symptom: loading never finishes and all resource packs get disabled.
Cause: Porting Lib (inside Sophisticated Backpacks and Storage) and porting_lib_ufo (inside Create Reforged) add the same methods to Minecraft's Transformation class, and Java refuses to run them.
Fix: this mod provides one shared implementation of those methods, so both libraries work.

2. You are kicked from your world a few seconds after joining

Symptom: "ticking exception on your player".
Cause: porting_lib_ufo asks every entity for its size while the entity is still being created; Cobblemon's Pokemon are not ready at that point and crash on every spawn.
Fix: Pokemon get a safe default size until they finish loading.

3. Create Aeronautics Reforged crashes at startup on older loaders

Symptom: ClassCastException: ArrayList cannot be cast to AnnotationNode.
Cause: Aeronautics is built against a newer Mixin annotation format that the MixinExtras in older Fabric Loaders (tested: 0.18.4 and 0.19.2) cannot read. This is not a bug in Aeronautics, and Fabric Loader 0.19.5 (COBBLEVERSE 1.8.0) reads it without help.
Fix: on older loaders, those annotations are converted in memory to the older format. The Aeronautics jar is not modified.

4. REI shows no Create machine recipes

Symptom: Poke Ball lids, bases and mechanisms look impossible to craft.
Cause: Create Reforged only ships a JEI plugin, and COBBLEVERSE uses REI.
Fix: this mod adds a REI plugin for Create machine recipes:

13 machine categories plus sequenced assembly, with the machines as workstations, chance outputs, heat requirements and a step-by-step view of sequenced assembly. The recipes of the bundled ports are included.

Shown Crushing, milling, pressing, mixing, compacting (packing), deploying, item application, spout filling, draining, sawing, sandpaper polishing, fan washing, fan haunting, sequenced assembly
Not shown yet Mechanical crafting, fan smoking and blasting, block cutting, automatic crafting and brewing

Fabric ports of NeoForge addons, adapted to Create Reforged. Each one keeps its original license and credit:

Also compatible with

These mods cannot be bundled because their licenses do not allow redistribution, but they can be installed alongside:

  • Cobblemore Library (Fabric). Requires Pommel.
  • Cobblemon: Create Industries. It has no Fabric 1.21.1 version yet; if its author releases one, it should work with this setup.

Not included

Mod Reason
Create Better FPS It optimizes Create 6's renderer, which Create Reforged does not use
Create Dynamic Light It needs Sodium Dynamic Lights and Sodium Options API, which have not been tested with the Sodium version in COBBLEVERSE

Changelog

Version Changes
1.1.3-beta Updated the bundled Create Cobblestone port from 1.4.10 to 1.5.1. The Mechanical Generator gets a configurable break time (breakTime, off by default), an invalid generator type no longer crashes while loading a world, and the block no longer hides the faces of blocks next to it. The two deepslate generator options were removed from the config, as upstream did: deepslate generators now come only from datapacks
1.1.2-beta Added the missing blockstate files for the fluids of Create Cobblemon Potion and Create: Cobblemon Balls Overhaul. Without them the game logged about 20,700 "missing model" warnings every time resources loaded
1.1.1-beta The annotation conversion for Aeronautics now runs only on loaders that need it, instead of touching every mod on every loader. Corrected the wording in the log and the mod description
1.1.0-beta REI support for Create machine recipes (Create Reforged only had a JEI plugin), including those of the bundled ports. Not shown yet: mechanical crafting, fan smoking/blasting, block cutting and the automatic crafting/brewing categories
1.0.0-beta First release: Porting Lib conflict fix, Pokemon spawn kick fix, Aeronautics startup crash fix, 5 bundled ports

Instalación

  1. Instala el modpack COBBLEVERSE.
  2. Añade a mods: Create Reforged [Unofficial], Create Aeronautics [Unofficial] (con su dependencia Sable) y este mod.

  5. Abre el juego.

Qué arregla

  • El congelamiento en la pantalla de carga causado por dos copias de Porting Lib.
  • La expulsión del mundo cuando aparecen Pokémon.
  • El crash de Create Aeronautics Reforged al arrancar con versiones antiguas de Fabric Loader (probado: 0.18.4 y 0.19.2), sin modificar su jar. No es un error de Aeronautics.
  • Recetas de Create en REI. Create Reforged solo trae plugin para JEI, así que REI no mostraba ninguna receta de máquinas (prensa, deployer, mezcla, ensamblaje secuenciado...). Ahora se muestran, incluidas las tapas, bases y mecanismos de las Poké Balls. Todavía no se muestran: crafteo mecánico, ahumado y fundido con ventilador, corte de bloques, y crafteo y elaboración de pociones automáticos.

Qué incluye

Ports a Fabric, con crédito a sus autores: Create Threaded Trains, Create Cobblestone (1.5.1), Create: Cobblemon Balls Overhaul, Create Cobblemon Potion y las Aviator's Goggles en un slot de Accessories.

Novedades de 1.1.3-beta

El port de Create Cobblestone pasa de 1.4.10 a 1.5.1: tiempo de rotura configurable para el Mechanical Generator (breakTime, desactivado por defecto), ya no crashea con un tipo de generador inválido y no oculta las caras de los bloques de al lado.
